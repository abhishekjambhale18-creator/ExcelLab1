### 📌 Project Overview
This lab introduces the D-Mart retail dataset and calculates the most important business metrics using fundamental Excel formulas. It establishes a strong foundation for all subsequent advanced analyses.

### 📁 Dataset Snapshot

| Metric              | Value                  |
|---------------------|------------------------|
| Total Orders        | 15,345                 |
| Total Sales         | ₹39,262,877.52         |
| Total Profit        | ₹6,872,139.81          |
| Date Range          | 2023 – 2024            |
| Regions             | East, West, North, South |
| Product Categories  | Clothing, Electronics, Grocery, Home Care, Personal Care |

### 🛠️ Skills Practiced
- Core Excel formulas (`SUM`, `COUNT`, `MIN`, `MAX`)
- Creating a clean summary dashboard
- Understanding retail data structure
- Data organization best practices

### 🔍 How to Explore
1. Open `ExcelLab1.xlsx`
2. Navigate to **Sheet2** to view the summary dashboard
3. Review Total Records, Total Sales, Total Profit, Min/Max Discount, and Payment Mode distribution

### 📈 Key Insights
- The dataset contains **15,345** clean transaction records
- Discount values range from **0% to 50%**
- Payment modes (UPI, Card, Cash) are almost evenly distributed
